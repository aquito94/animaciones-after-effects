# Animaciones After Effects

Repositorio base para proyectos de animación en After Effects: estructura, convenciones y entregables.

## Estructura

```
proyectos/        Un carpeta por proyecto (ver _plantilla/)
recursos/         Material reutilizable: plantillas, LUTs, fuentes, audio
entregables/      Renders finales listos para enviar al cliente
docs/             Convenciones y guías internas
```

## Flujo de trabajo

1. Crear el proyecto copiando `proyectos/_plantilla/` con el nombre según la convención.
2. Documentar el brief y los objetivos en `brief.md` antes de animar.
3. Trabajar en `comps/` y guardar el `.aep` del proyecto en la raíz de la carpeta.
4. Exportar a `exports/` durante la revisión y copiar la versión aprobada a `entregables/`.

Convención de nombres: ver [docs/convencion-nombres.md](docs/convencion-nombres.md).
