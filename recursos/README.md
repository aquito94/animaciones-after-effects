# Recursos

- `plantillas-ae/`: proyectos base reutilizables (.aep, .aet)
- `luts/`: tablas de color
- `fuentes/`: solo fuentes con licencia verificada para uso comercial
- `audio/`: música y efectos con licencia documentada

Incluir en cada archivo, o en un `LICENCIAS.md`, el origen y la licencia.
